---------------------------
METHODOLOGICAL INFORMATION
---------------------------

1. Description of methods used for collection/generation of data: Daphnia magna were exposed to plastic particles (PS, PMMA, PVC, PE, PTFE) separately, at environmentally relevant concentrations. After exposure, histological slices were obtained using a cryotome. The histological slices were then stained with hematoxylin and eosin. After that, the histological slices were imaged. Images were captured using Cytoviva's enhanced darkfield hyperspectral microscope. Spectral information was captured using a spectrophotometer (Specim, ImSpector V10E). Spatial information in the x-y plane and hyperspectral data in the z-plane are stored in a hypercube in the ENVI 4.8 software. Data was extracted to text files for spectra files, and tif files for images. When hyperspectral data were presented, 50 pixels from an image of biomass or polymer were collected. Data collection is also described in: 10.1039/d5en00992h

2. Methods for processing the data: Hyperspectral data were normalized. For every wavenumber, the average intensity over 50 pixels was calculated. This produced an average spectrum over 50 pixels. The maximum intensity from this average spectrum was found and used to normalize the data. The normalized data is then plotted with intensity on the y-axis and wavelength on the x-axis. 

3. Instrument- or software-specific information needed to interpret the data: A CytoViva enhanced darkfield hyperspectral microscope was used to capture images and spectral data. The microscope was fitted with an Olympus BX41 upright microscope CytoViva® high-aperture darkfield condenser (CytoViva Inc., USA) and a spectrophotometer (Specim, ImSpector V10E). Data acquisition was completed using ENVI 4.8 software, and then processed using Microsoft Excel. 

4. Standards and calibration information, if appropriate: N/A

5. Environmental/experimental conditions: experimental conditions for each file differed. In general, a model organism was exposed to plastic particles at environmentally relevant concentrations, and then histological slices were acquired. Subsequently, slices were stained with H&E stain and then imaged on the enhanced darkfield hyperspectral microscope. The conditions for each experiment changed slightly, and are explained in detail here: 10.1039/d5en00992h
